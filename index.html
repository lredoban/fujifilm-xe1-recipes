Balance des blancs, une fois pour toutes.

Le shift WB n'est pas mémorisé par slot C1–C7 mais par type de WB, globalement. Réglé une fois pour un type, il reste pour ce type.

Comme chaque slot couleur a un type de WB unique, chaque shift se règle une seule fois puis ne bouge plus. Vérifier toutefois la valeur affichée avant une session si beaucoup de manipulations menu — le firmware ne persiste pas toujours de façon fiable.

Procédure · menu WB → choisir le type → appuyer à droite → grille 19×19 → régler R/B → valider.
